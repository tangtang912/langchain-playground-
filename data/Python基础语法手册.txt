## 第1页：变量、数据类型、输入输出

### 1. 变量

```python
name = "小明"       # 字符串
age = 18            # 整数
score = 95.5        # 浮点数
is_pass = True      # 布尔值
```

> **变量 = 贴了标签的盒子，标签是变量名，盒子里放数据。**

---

### 2. 常见数据类型

| 类型 | 写法 | 例子 | 用途 |
|------|------|------|------|
| `str` 字符串 | `"..."` 或 `'...'` | `"hello"` | 文字 |
| `int` 整数 | 直接写数字 | `100` | 计数 |
| `float` 浮点数 | 带小数点 | `3.14` | 小数 |
| `bool` 布尔 | `True` / `False` | `True` | 判断 |
| `None` 空值 | `None` | `None` | 没有值 |

```python
# 查看类型
print(type("hello"))   # <class 'str'>
print(type(18))        # <class 'int'>
```

---

### 3. 类型转换

```python
int("123")     # 字符串 → 整数：123
str(456)       # 整数 → 字符串："456"
float("3.14")  # 字符串 → 浮点数：3.14
```

---

### 4. 输入与输出

```python
# 输出
print("你好")                  # 你好
print(f"小明今年{18}岁")       # f-string：小明今年18岁

# 输入
name = input("请输入名字：")    # 用户输入的内容，永远是字符串类型
age = int(input("请输入年龄："))  # 需要数字时，用 int() 转换
```

## 第2页：运算符与条件判断

### 1. 算数运算符

```python
a = 10
b = 3

a + b   # 加：13
a - b   # 减：7
a * b   # 乘：30
a / b   # 除：3.3333...（永远是浮点数）
a // b  # 整除：3（去掉小数）
a % b   # 取余：1（10除3余1）
a ** b  # 幂：1000（10的3次方）
```

---

### 2. 比较运算符（返回 True/False）

```python
==   # 等于
!=   # 不等于
>    # 大于
<    # 小于
>=   # 大于等于
<=   # 小于等于
```

---

### 3. 逻辑运算符

```python
and   # 两边都True才True    （且）
or    # 只要一边True就True   （或）
not   # 取反                 （非）

# 例子
(age > 18) and (score > 60)   # 年龄大于18 且 分数大于60
(age < 18) or (is_vip)        # 年龄小于18 或 是VIP
not is_pass                    # 取反
```

---

### 4. if 条件判断

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 80:       # elif = else + if，可多次使用
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

> **格式口诀：if 开头，elif 中间，else 收尾，冒号加缩进。**

## 第3页：循环

### 1. while 循环

```python
# 基本结构
count = 1
while count <= 5:
    print(f"第{count}次")
    count += 1       # ← 必须有终止条件，否则死循环
```

> **while = 条件为真就一直重复**

---

### 2. for 循环

```python
# 遍历列表
names = ["小明", "小红", "小刚"]
for name in names:
    print(name)

# range() 生成数字序列
for i in range(5):       # 0,1,2,3,4（不含5）
    print(i)

for i in range(1, 6):    # 1,2,3,4,5（从1到5）
    print(i)
```

> **for = 挨个取出来，取完为止**

**while vs for 选择：**
- 知道循环次数 → 用 `for`
- 不知道次数，等条件满足才停 → 用 `while`

---

### 3. break 与 continue

```python
# break：直接结束整个循环
for i in range(10):
    if i == 5:
        break          # 到5就停
    print(i)            # 输出 0,1,2,3,4

# continue：跳过本次，继续下一次
for i in range(5):
    if i == 2:
        continue        # 跳过2
    print(i)            # 输出 0,1,3,4
```

## 第4页：五大数据容器

### 1. 列表 list ── `[]` 可改，有序

```python
fruits = ["苹果", "香蕉", "橘子"]
fruits.append("西瓜")         # 末尾添加
fruits[0]                     # 按索引取值 → "苹果"（从0开始）
fruits[1] = "葡萄"            # 修改
len(fruits)                   # 长度 → 3
```

### 2. 元组 tuple ── `()` 不可改，有序

```python
point = (3, 4)
point[0]       # 3
# point[0] = 5  # ❌ 报错！元组不能修改
```

### 3. 字符串 str ── `""` 不可改，有序

```python
s = "hello world"
s[0]          # "h"
s.upper()     # "HELLO WORLD"
s.split()     # ["hello", "world"]  → 按空格分割成列表
",".join(["a","b"])  # "a,b"  → 列表拼成字符串
```

### 4. 集合 set ── `{}` 可改，无序，不重复

```python
nums = {1, 2, 3, 3}
print(nums)   # {1, 2, 3}  自动去重！
```

### 5. 字典 dict ── `{key: value}` 键值对

```python
student = {"name": "小明", "age": 18, "score": 95}
student["name"]         # 取值 → "小明"
student["age"] = 19     # 修改
student["hobby"] = "篮球"  # 新增
```

---

### 容器选择口诀

```
有顺序 用列表   [] 改不坏
只读不改 元组  () 保安全
去重统计 集合   {} 自动排
一一对应 字典   {key: value} 查得快
```

## 第5页：函数与面向对象

### 1. 函数定义

```python
def 函数名(参数):
    """文档字符串：说明函数用途"""
    # 函数体
    return 返回值    # 可选

# 例子
def add(a, b):
    """两数相加"""
    return a + b

result = add(3, 5)   # 调用 → 8
```

---

### 2. 函数类型

```python
# 无参无返回
def say_hi():
    print("你好")

# 有参有返回
def greet(name):
    return f"你好，{name}"

# 默认参数
def power(x, n=2):        # n有默认值，调用时可不传
    return x ** n

power(3)      # 3² = 9
power(3, 3)   # 3³ = 27
```

---

### 3. 面向对象基础

```python
class Student:                               # 类名首字母大写
    def __init__(self, name, age):           # 构造方法，创建对象时自动调用
        self.name = name                     # self = 对象自己
        self.age = age

    def introduce(self):                     # 方法 = 类里面的函数
        print(f"我叫{self.name}，今年{self.age}岁")

# 使用
stu = Student("小明", 18)     # 创建对象（实例化）
stu.introduce()               # 调用方法 → 我叫小明，今年18岁
```

> **类 = 模板（学生登记表），对象 = 根据模板造出来的具体实例（小明这张表）。**

---

### 4. 异常处理

```python
try:
    num = int(input("请输入数字："))
    result = 10 / num
except ValueError:
    print("输入的不是数字！")
except ZeroDivisionError:
    print("不能除以0！")
else:
    print(f"结果：{result}")   # 没出错才执行
finally:
    print("程序结束")          # 不管出不出错都执行
```

> **try = 试试看，except = 出错了怎么办**

### 5. 文件操作

```python
# 读文件
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()

# 写文件
with open("data.txt", "w", encoding="utf-8") as f:
    f.write("hello")

# 追加
with open("data.txt", "a", encoding="utf-8") as f:
    f.write("追加内容")
```

> **`with open` 自动关闭文件，不用手动 close。**

---

### 6. JSON 读写

```python
import json

# Python对象 → JSON字符串 → 写文件
data = {"name": "小明", "age": 18}
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False)

# JSON文件 → Python对象
with open("data.json", "r", encoding="utf-8") as f:
    data = json.load(f)
```
